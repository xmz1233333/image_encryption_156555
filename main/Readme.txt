main 文件夹代码说明
====================

本文件夹和子文件夹中的整套加密解密代码都是完整的，都可以直接运行对应测试脚本。

一、加密解密相关函数
--------------------

CML.m
    生成 EESMCML 系统的时空混沌矩阵。

generate_chaos_01.m
    生成 1D-EESM 混沌序列。

generate_chaos_sequence.m
    生成扩散阶段使用的混沌序列。

Generate_index_matrix.m
    生成三个三维索引矩阵，用于置乱和跨通道混淆。

z_encrypt.m
    指数扰动加密，对应论文中的 CEIPA 初始扰动阶段。

z_decrypt.m
    指数扰动解密，对应 z_encrypt 的逆过程。

zhiluan.m
    使用三个索引矩阵进行空间置乱和跨通道置乱。

izhiluan.m
    zhiluan 的逆置乱过程。

kuosan.m
    拉普拉斯特征调制扩散加密。

ikuosan.m
    kuosan 的逆扩散过程。

laplace_diffusion_encrypt.m
    正向和逆向拉普拉斯扩散加密。

laplace_diffusion_decrypt.m
    正向和逆向拉普拉斯扩散解密。

二、主程序
----------

run_main.m
    读取图像，执行完整加密和解密，显示原始图、加密图、解密图，
    以及对应的 RGB 直方图。

三、性能测试脚本
----------------

test_entropy.m
    计算明文和密文三个颜色通道的信息熵。

test_correlation.m
    计算明文和密文在水平、垂直、对角线方向的相邻像素相关性，
    并绘制相关性散点图。

test_npcr_uaci.m
    修改一个像素后重新加密，计算 NPCR 和 UACI。

test_speed.m
    测量加密时间、解密时间、内存占用和吞吐量。


四、子文件夹
------------

噪声和密钥空间测试/
    这个子文件夹用于噪声攻击、裁剪攻击和密钥空间测试。
    该子文件夹内同样提供了一套完整的加密解密代码。
    为了方便测试，混沌序列的计算已经整合到加密函数中，
    因此该子文件夹内的测试脚本不需要再单独调用混沌序列生成函数。

    主要脚本：

    noise_test.m
        进行椒盐噪声攻击和裁剪攻击。

    key_space.m
        进行密钥空间计算和密钥敏感性测试。



五、main 文件夹和子文件夹的区别
------------------------------

main 文件夹：
    使用 main 文件夹内这一套加密解密函数。
    测试脚本中仍然需要单独调用混沌序列生成函数，
    例如 generate_chaos_01、generate_chaos_sequence 和 CML。

噪声和密钥空间测试文件夹：
    主要针对噪声攻击、裁剪攻击和密钥空间测试单独组织，
    里面使用该子文件夹内自己的那一套加密解密函数。
    为了方便测试，混沌序列的计算已经整合到加密函数中，
    因此测试脚本中不需要再单独调用混沌序列生成函数。
    这样能更方便的测试噪声和密钥敏感性
